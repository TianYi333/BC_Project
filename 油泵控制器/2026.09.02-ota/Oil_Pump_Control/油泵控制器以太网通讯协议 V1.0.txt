    "ts": 1746601200,
    "seq": 1001,
    "sign": "7F2D91C0"

| 字段 | 类型 | 必填 | 说明 |

#### register（设备发送） 设备注册报文
**用途**：TCP连接建立后立即发送，用于绑定设备与TCP连接，是业务通信的前置条件。
json
{
    "type": "register",
    "device_id": "5102002F0030",
    "mac": "00:80:E1:30:00:2F",
    "model": "LUB-PUMP-V1.0",
    "firmware_ver": "1.0.0",
    "ts": 1746601200,
    "seq": 1,
    "sign": "3A7F2D11"
}
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | 是 | 消息类型标识，固定为"register" |
| device_id | string | 是 | 设备唯一标识（通常使用SN），用于业务层识别 |
| mac | string | 是 | MAC地址，用于物理层识别 |
| model | string | 是 | 设备型号 |
| firmware_ver | string | 是 | 固件版本 |
| ts | int64 | 是 | Unix时间戳 |
| seq | int | 是 | 自增序列号，**设备重启后必须从1开始** |
| sign | string | 是 | HMAC-SHA256前8位 |

**重要说明**：
- 设备必须在TCP连接建立后的1秒内发送register报文
- 网关收到register后才会将设备标记为在线状态
- 网关会检测seq=1来识别设备重启，并重置序列号管理

sign	string	是	HMAC-SHA256签名前8位


####电机启停事件上报 (motor_event_report)
用途：设备电机启动 / 停止事件发生时主动上报告警事件。
json
{
    "type": "motor_event_report",
    "device_id": "5102002F0030",
    "event": 1,
    "tick_ts": 1746601241,
    "ts": 1746601241,
    "seq": 1010,
    "sign": "71D3AC29"
}
字段	类型	必填	说明
type		string	是	消息类型标识，固定为"motor_event_report"
device_id	string	是	设备标识
event		int		是	事件：1=MOTOR_EVT_START 电机启动；2=MOTOR_EVT_STOP 电机停止
tick_ts		int64	是	Unix 秒 UTC 时间戳**，对应结构体`tick`字段
ts			int64	是	Unix时间戳
seq			int		是	设备消息序列号，递增
sign			string	是	HMAC-SHA256签名前8位
