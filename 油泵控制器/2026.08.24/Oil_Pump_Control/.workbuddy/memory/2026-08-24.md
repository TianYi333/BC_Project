## IO 监视页 debug_io_monitor_callback 实现（UserCode/Logic/oled_page.c）
- 原占位显示 "Function Not Implemented"。现改为实时读取三个输出 IO 引脚实际电平（HAL_GPIO_ReadPin，非缓存变量）：
  - DO_OUTPUT_0(PE3) 泄压阀：高=OPEN / 低=CLOSE（与 Valve_Drive() 约定一致）
  - DO_OUTPUT_1(PE4) MF：HIGH/LOW
  - DO_OUTPUT_2(PE5) DIR：HIGH/LOW
- 实现细节：函数内 static const io_pin_t out_io[3] 表驱动；逐行 y=44/64/84 显示；底部 y=104 提示 "Long Press Return"；长按 ENCODER_PUTH_LONG 退出（交互不变）。
- 宏来源：DO_OUTPUT_x 来自 main.h，DIR/MF 别名来自 step_motor.h；oled_page.c 已包含二者。GPIO 读为单寄存器读，无需加锁。

## IO 监视页改名为功能名（同函数追加修改）
- 用户要求"名字按相应功能显示"。将显示标签改为功能名（不再用引脚/信号名）：
  - "Relief Valve" (PE3 泄压阀) / "Motor Free" (PE4 MF 脱机) / "Motor Dir" (PE5 DIR 方向)
- 状态也按功能解释（用 step_motor.h 极性宏保证与驱动一致）：
  - Valve: 高=OPEN 低=CLOSE
  - MF: ==MF_RELEASE_PIN_STATE→"FREE" 否则"LOCK"（共阴极下 高=FREE脱机/低=LOCK锁轴）
  - DIR: ==DIR_FORWARD_PIN_STATE→"FWD" 否则"REV"
- 实现：io_pin_t 增加 io_type_t type 字段（IO_VALVE/IO_MF/IO_DIR），显示时 switch 映射状态字符串。
- 字体 VALUE_FONT=u8g2_font_10x20_tf(比例字体~10px/字)，最长 "Relief Valve:OPEN"(17字)≈170px < 256宽，放得下。
