## 修复：速度设置页「最大速度加不上去」bug + 选中标记语义纠正（用户反馈）
- 用户反馈两条：①"未选中状态为 >，选中为 *"（我上次理解反了）；
  ②**值无法变大，只能变小，变为200后不能加大也不能变小**。
- **Bug 根因**：上一版把「最大速度」项的上限也取 `max_val`（即它自身当前值），
  CW 时 `*cur <= limit - STEP` 恒为 false → 直接 `*cur = limit` 钳死；
  故该项只能往下减，减到下限 200 后彻底卡住（CCW 停在 200、CW 也停在 200）。
  「目标速度」项因 limit 取的是 max_val（另一个变量）故能正常增大 —— 与用户观察到的现象吻合。
- 修复（仅 `UserCode/Logic/oled_page.c`）：
  - 新增宏 `MOTOR_SPEED_MAX_RPM = 3000`（最大速度项的绝对上限）。
  - 上限按项区分：`limit = (sel == MOTOR_SPEED_ITEM_MAX) ? MOTOR_SPEED_MAX_RPM : max_val;`
    → 最大速度项可在 200~3000 自由增减；目标速度项仍以 max 为上限（保持 base<=max）。
  - 选中标记改为：**选中项 '*'、未选中项 '>'**（此前是 选中'*'/未选中'空格'）。
- 模拟验证（复刻改后逻辑，6 个场景全过）：
  ①最大速度 CW/CCW 正常；②减到 200 后 CW 能回到 250/300（不再卡死）；
  ③增到 3000 正确停住；④目标速度正常增减；⑤base 增到 max 后被钳住不越界；
  ⑥base 减到 200 停住且能再加回。`limit-STEP` 最小 150，无 uint16_t 下溢。
- 验证：`-std=gnu11` 语法检查 EXIT=0、无 warning；行尾 1588 CRLF / 0 纯 LF。
