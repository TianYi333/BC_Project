bilingual (Chinese/English) OLED UI switch, together with the completion of the full
OLED Chinese localization and the restoration of the English UI to the pre-localization

============================================================
一、新增：OLED 中英文双语切换
============================================================
1. 新增 UserCode/Logic/oled_lang.h
   - g_oled_lang：当前语言标志（OLED_LANG_CN=0 / OLED_LANG_EN=1）
   - OLANG(cn, en)：就地双语宏，在每个文案调用点给出中英两套字符串
   - oled_lang_init() / oled_lang_toggle()：语言读取与切换
2. 语言持久化（不进 main_config，不占 Modbus 寄存器）
   - FlashDB 独立 key "oled_lang"，值 "0"=中文 / "1"=英文
   - 位置：sysdb 数据库 -> fal 分区 ef_kvdb1 -> W25Q64 偏移 0x00000，64KB
   - syncif.c / syncif.h 新增 sysdb_get_u8() / sysdb_set_u8()
   - 切换语言不会改写 main_config，Modbus 侧完全不受影响
3. 切换入口
   - 系统设置二级菜单新增「语言/Language」项（7 项 -> 8 项），短按切换、立即刷新
   - 一级菜单结构保持 6 项不变
   - 菜单项名称用中/英两张表，由 oled_lang_apply_menu() 在运行时改 item_name 指针
4. 语言感知绘制原语（oled_page.c）
   - draw_lang_text(u8g2, f_cn, f_en, text, x, cn_y, en_y)：中文走 cn_font_* 点阵 +
     u8g2_DrawUTF8，英文走原厂 u8g2 字体 + u8g2_DrawStr，中英各一套基线
   - lang_text_width(u8g2, f_cn, f_en, text)：按当前语言测宽
5. 英文界面文案全部复用汉化前的原厂文案（取自 _backup/oled_page.c.bak_speed2state_
   20261118_164528），未自行翻译：
     一级菜单 Home Page / System Settings / Test Running / Unit Test / About Device / Reboot
     二级菜单 Serial Port / P Model Init / Q Model Init / P Model Speed / Q Model Speed /
              Restore Factory / Language / Back
   运行消息（running_logic.c 37 处 show_oled_msg）同样取用原厂英文：
     motor init ... / run task %d / waiting sen ... / init motor error ... / p ready to %d /
     init sen error ... / task %u-%lu / motor error ... / P motor error ... / err: sen ... /
     P zero not ready ! / P running failure . / P motor release protect . / Q zero not ready ! /
     Q motor release protect . / Q running failure . / waiting sen to %d / sen %d timeout

1. New file UserCode/Logic/oled_lang.h: g_oled_lang flag (OLED_LANG_CN / OLED_LANG_EN),
   the OLANG(cn, en) macro, and oled_lang_init() / oled_lang_toggle().
2. Language persistence without touching main_config or the Modbus map: dedicated FlashDB
   key "oled_lang" ("0"=CN, "1"=EN) inside the sysdb database / ef_kvdb1 partition
   (W25Q64 offset 0x00000, 64KB), read and written through the new sysdb_get_u8() /
   sysdb_set_u8() in syncif.c / syncif.h.
3. Switch entry: a new "语言/Language" item in the System Settings sub-menu (7 -> 8 items),
   short press toggles and refreshes immediately. The main menu keeps its 6 items. Menu
   labels are held in two CN/EN tables and swapped by oled_lang_apply_menu() at runtime.
4. Language-aware drawing primitives in oled_page.c: draw_lang_text() and lang_text_width(),
   with separate baselines for Chinese and English.
5. All English strings reuse the original pre-localization wording taken from the backup
   baseline; nothing was re-translated. Menu labels and the 37 runtime messages in
   running_logic.c follow the same rule.

二、英文界面还原为汉化前原厂样式
============================================================
1. 字体（汉化前基线原厂字体）
   标题/品牌 = u8g2_font_ncenB14_tr，正文 = u8g2_font_9x15_tf，
   编辑页数值与速度行 = u8g2_font_10x20_tf，重启文案 = u8g2_font_ncenB18_tr，
   底部状态栏 = u8g2_font_6x10_tf；中文仍用 cn_font_12/16/16_bold + DrawUTF8
2. 基线坐标（中英各一套，共 45 个绘制点）
   底部状态栏 H-3 -> H-6；关于页底部 H-6 -> H-12；各页标题 19/20 -> 16；
   主页温湿度 103 -> 100；编辑页说明 94 -> 82；恢复出厂正文 62 -> 60；重启页 75 -> 70
3. 排版结构
   主页温湿度：英文改回原厂整行 "T: 25.30C" / "H: 55.20%"（x=20/148, y=100）
   重启页：英文改回 ncenB18_tr 左对齐 x=50, y=70（中文仍居中 y=75 并补三点省略号）
   菜单页：标题 ncenB14_tr@16、菜单项 9x15_tf@menu_y+8、状态栏 6x10_tf@H-6
4. 英文文案细节
   恢复出厂英文标题用原厂全大写 RESTORE FACTORY
   系统设置页英文状态栏用操作提示语 Long press to return（不用原厂的页标题）
5. 刻意未照搬原厂的两处（因功能已变更）
   速度页：英文只做文案翻译（Max Speed / Target Speed / RPM），中英同结构
           （单行合并、'>'/'*' 前缀、行距 32px），不还原原厂的"标签+值"两段式排版
   速度页第二项英文用 Target 而非原厂基线版的 Base（现版功能是目标速度）

The English UI was restored to the pre-localization factory look: original fonts,
original baselines (45 draw points, Chinese and English now have their own y),
and original layout structure for the home temperature/humidity line, the reboot text
and the menu pages. Two items are intentionally NOT copied from the factory version
because the functionality has changed: the motor-speed page keeps the Chinese single-line
layout (only the wording is translated), and its second item is named "Target" instead
of the factory "Base".

三、字库补充：新增「语」「言」
============================================================
- 现象：系统设置菜单「语言」项在中文模式下显示空白
- 根因：点阵字库中根本没有「语」(U+8BED)、「言」(U+8A00) 两个字形，U8G2 查不到即画空白
- 修改：UserCode/Drivers/Oled/cn_font_gen.py 字符表补入 "语"、"言" 后重新生成字库
- 结果：中文字符 179 -> 181；cn_font_12/16/24 分别 +75 / +86 / +125 字节；
  cn_font_16_bold 不变；ASCII 95 个字形逐字节比对完全一致（点号等既有修复未受影响）
- 校验：脚本内置的逐像素解码自校验通过，另模拟 U8G2 查找路径确认三个字体均可命中

Blank "语言" menu entry in Chinese mode was caused by the two missing glyphs "语" and "言"
in the bitmap font. They were added to cn_font_gen.py and the font was regenerated
(181 CJK characters now). The ASCII segment is bit-identical to before.
