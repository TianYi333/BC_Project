# 2026-09-10 工作日志

## PHY 自协商重触发（LAN8720A/LAN8742 仅 10M 问题）
- 故障：上电后 LAN8742 协商到 10M/HD，`[ETH] link UP (phy=5, 10M/HD)`，link 14s 才 up。
  根因**不在固件**：固件从未 `LAN8742_StartAutoNego/SetLinkState` 强制速率，MAC 只是照抄 PHY 协商结果；
  10M 来自对端(PC 网卡固定速率)/网线差/中间 10M 设备 → 自协商失败回退 10Base-T。
- 用户选方案 (a)：在 `LAN8742_Init()` 后补自协商触发。但 `LAN8742_StartAutoNego()` 仅置 `AUTONEGO_EN`
  位（上电默认已置 1），**不会真正重启协商**；必须同时置 `RESTART_AUTONEGO (0x0200)` 位。
- 落盘改动（`LWIP/Target/ethernetif.c`，均在 CubeMX 保护区）：
  1. USER CODE 4 新增静态 `lan8742_restart_autonego()`：读 BCR，OR `AUTONEGO_EN|RESTART_AUTONEGO` 写回。
  2. 链路线程 USER CODE 区"PHY 速率校正"块内加**一次性**重触发：首次观察到 link up 且非 100M/FD
     时调用之，每 boot 仅一次（`an_retried` 标志），避免反复 flap 死循环。
  3. `PHY_PRE_CONFIG` 加注释说明为何放在 link thread 而非 Init 之后（init 时 link 通常还 DOWN）。
- 编译验证：ninja Exit 0，FLASH 204692B / RAM 66.59% / DTCM 0B；elf 含 `[ETH] PHY auto-nego re-triggered`。
- **提醒**：此改动为"二选一"锦上添花，治不了 10M 根因；仍需用户侧换 CAT5e 短线直连 + PC 网卡设"自动协商"。
